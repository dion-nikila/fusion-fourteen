# fusion14 — The art of living, in batik

An independent website concept for Fusion Fourteen, inspired by its Sri Lankan batik, artisanal fashion and colourful interiors. Built with semantic HTML, responsive CSS and lightweight JavaScript.

## Features
- Responsive editorial layout, with a dedicated mobile composition and menu
- Collection filters and accessible collection-detail dialogs
- Direct Instagram enquiries and store directions
- Reduced-motion support, keyboard focus states and native modal focus management
- No build step, tracking, credentials or customer-data collection

## Preview
Serve `dist` with any static server, for example `python3 -m http.server 4173 --directory dist`.

## Publishing
GitHub Pages serves the `docs` copy. After editing `dist`, run `python3 sync-pages.py` to update it. The `.openai/hosting.json` manifest supports the accompanying Sites publication.

## Brand and photography
This is a website concept, not an assertion of affiliation. Brand facts and collection imagery were reviewed on https://www.instagram.com/fusionfourteen/ on 18 October 2026. Store photographs are from https://trippin.world/spot/fusion14-Colombo. Collection names come from the brand's public posts.
